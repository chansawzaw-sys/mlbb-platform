# စမ်းသုံးကြည့်ဖို့ — GitHub + Codespaces လမ်းညွှန်

## (A) GitHub မှာ repo အလွတ် ဖွင့်ပုံ

၁။ github.com ဝင်၊ အကောင့် **chansawzaw-sys** နဲ့ sign in ဝင်ပါ
၂။ ညာဘက်အပေါ် **+** → **New repository** နှိပ်ပါ
၃။ Repository name မှာ **video-translator** ရိုက်ပါ
၄။ **Public** ရွေးပါ
၅။ အောက်က "Add a README file" စတာတွေ **ဘာမှ အမှန်ခြစ် မထည့်ပါနဲ့** (repo အလွတ် ဖြစ်ရမယ်)
၆။ **Create repository** နှိပ်ပါ
၇။ ပြီးရင် ကျွန်တော့်ကို ပြောပါ — code တင်ပေးပါမယ်

## (B) Codespace ဖွင့်ပြီး app သုံးပုံ

၁။ repo စာမျက်နှာမှာ အစိမ်း **Code** ခလုတ် → **Codespaces** tab → **Create codespace on main** နှိပ်ပါ
၂။ Setup ပြီးအောင် စောင့်ပါ (ပထမအကြိမ် မိနစ် အနည်းငယ် ကြာနိုင်တယ် — "SETUP DONE" ထိ)
၃။ အောက်ခြေက **PORTS** tab မှာ **8611 (Video Translator App)** ကို ညာကလစ် / ဖိနှိပ်ပြီး **Port Visibility → Public** ပြောင်းပါ
၄။ PORTS ထဲက 8611 ရဲ့ link (🌐) ကို နှိပ်ဖွင့်ပါ — app ပွင့်လာပါမယ်
၅။ စမ်းရင် ဗီဒီယို **အတို** (၁–၂ မိနစ်) link အရင် သုံးပါ

မှတ်ချက်: Codespace က အခမဲ့ အကန့်အသတ် ရှိတယ်။ မသုံးဘဲ ထားရင် အလိုလို ရပ်သွားမယ် — ပြန်ဖွင့်လို့ရတယ်၊ ဗီဒီယို ရလဒ်ဖိုင်တွေ ပြန်စရမယ်။
