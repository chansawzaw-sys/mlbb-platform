နောက်ဆုံး backup: —

ဖိုင် ပြန်ဖွင့်နည်း (ကိုယ့် computer မှာ):
openssl enc -d -aes-256-cbc -pbkdf2 -in vt-backup-YYYY-MM-DD.tar.gz.enc -out vt-backup.tar.gz
tar -xzf vt-backup.tar.gz
ပထမ command က passphrase တောင်းရင် အခု သတ်မှတ်တဲ့ passphrase ကိုပဲ ရိုက်ထည့်ပါ။ Passphrase မေ့သွားရင် ဖိုင်ကို ပြန်ဖွင့်လို့ လုံးဝ မရတော့ပါ — သေချာ မှတ်ထားပါ။

အသံ ရှင်းရှင်းလင်းလင်း ကြားရတဲ့ နေရာမှာ ပုံမှန် လေသံနဲ့ ၁–၂ မိနစ် စာလောက် ပြောထားရင် clone အရည်အသွေး ပိုကောင်းပါတယ်။ နမူနာ မူရင်းဖိုင်ကို ကိုယ့်ဖုန်းမှာပဲ သိမ်းထားပါ — ဒီ server ပေါ်မှာ သိမ်းမထားပါ။
