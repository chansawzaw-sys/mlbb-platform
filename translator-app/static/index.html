🎬 ဗီဒီယို မြန်မာဘာသာပြန်

ဗီဒီယိုလင့်ခ် ထည့်ရုံနဲ့ — စာသားထုတ် → မြန်မာပြန် → စာတန်းထိုး (ရုပ်ရှင်ပုံစံ) / အသံထွက် အစအဆုံးလုပ်ပေးမယ်။ အသံကို အချိန်ကိုက်အောင် အမြန်ညှိ၊ မလုံလောက်ရင် ဖရိမ်ရပ်ပြီး ဆက်ပြောပေးမယ်။

🔑 Gemini key (ဘာသာပြန် အတွက်)

Key ရှိရင် ဘာသာပြန် မြန်ပြီး အရည်အသွေး ကောင်းတယ်။ Chat ထဲ လုံးဝ မပို့ပါနဲ့ — ဒီ page ထဲမှာပဲ ထည့်ပါ, server ထဲမှာပဲ သိမ်းတယ်, ပြန်လည်း မပြပါ။ အခြေအနေ: …

ဒါက နမူနာ စာတန်း ဖြစ်ပါတယ် — စာတန်းရဲ့ အကျယ်၊ အရွယ်အစားနဲ့ နေရာကို ဒီမှာ မြင်နိုင်ပါတယ်

ပုံပေါ်မှာ — Logo ကို လက်နဲ့ ဆွဲရွေ့ နေရာချပါ။ မူရင်းစာ ဝါးချင်ရင် ဝါးချင်တဲ့နေရာကို လက်နဲ့ ဆွဲပြီး အကွက်ဆွဲပါ (အကွက်ဟောင်းထဲ ဆွဲရင် ရွေ့တယ်၊ နေရာသစ်မှာ ဆွဲရင် အကွက်အသစ် ဖြစ်တယ်)။ ဝါးထားတဲ့ အကွက်က ဗီဒီယို တစ်လျှောက်လုံး ဝါးပေးမယ်။

📝 မြန်မာ ဘာသာပြန်ကို စစ်ပြီး ပြင်ရန်

အင်္ဂလိပ် မူရင်းကို ကြည့်ပြီး မြန်မာစာကို လိုသလို ပြင်နိုင်တယ်။ ပြင်ပြီး "ပြန်လုပ်မယ်" နှိပ်ရင် အသံ + စာတန်း ပြန်လုပ်ပေးမယ်။

📝 မြန်မာ စာသား အပြည့်အစုံ ထည့်ရန်

ကိုယ်တိုင် (သို့) အပြင်မှာ ပြန်ထားတဲ့ မြန်မာ စာသား အပြည့်ကို ဒီမှာ ကူးထည့်လိုက်ရင် အပိုင်းတွေထဲ အလိုလို ခွဲထည့်ပေးမယ် — တစ်ကြောင်းချင်း ရေးထားရင် ကြောင်းအလိုက်၊ မဟုတ်ရင် ဝါကျ (။ / .) အလိုက် ခွဲမယ်။ ပိုနေရင် နောက်ဆုံး အပိုင်းထဲ ပေါင်းထည့်ပြီး၊ လိုနေရင် ကျန် အပိုင်းတွေ ဒီအတိုင်း ထားမယ်။ ခွဲထည့်ပြီးရင် အောက်က အပိုင်းတွေမှာ ပြန်စစ်/ပြင်နိုင်တယ်။
